# Java-OOP Resources

## Knowledge

- [Hessen: Bildungsstandards, Kerncurricula und Lehrpläne](https://kultusministerium.hessen.de/unterricht/kerncurricula-und-lehrplaene/)
  Offizielle Ministeriumsseite zu Kerncurricula (verifiziert 26.08.2026). Das konkrete KC-Dokument Informatik gymnasiale Oberstufe liegt dahinter unter „Curriculare Vorgaben“ und muss noch als Direktlink nachgetragen werden. Use for: Stoffauswahl und Fachbegriffe verbindlich gegenchecken.

- [Oracle Java Tutorials: Object-Oriented Programming Concepts](https://docs.oracle.com/javase/tutorial/java/concepts/)
  Primärquelle für Begriffsdefinitionen (Objekt = Zustand plus Verhalten, Klasse als Bauplan, Vererbung, Interface). Verifiziert am 26.08.2026. Use for: autoritative Definitionen, englische Fachtermini.
- [Java-Editor Homepage](https://javaeditor.org)
  Offizielle Seite der Schul-IDE von Gerhard Röhner (laut Wikipedia: Freeware/MIT, UML-Ansicht, interaktives Objekt-Erzeugen im BlueJ-Stil). Domain javaeditor.org, nicht .nl. Use for: Editor-spezifische Fragen, Installation zu Hause.
- [Wikibooks: Java Standard, Kapitel Objektorientierung](https://de.wikibooks.org/wiki/Java_Standard)
  Deutsches Open-Access-Lehrbuch mit Kapiteln zu Klassen, Objekten, Vererbung, Interfaces. Buch wird laut Selbstauskunft kaum gepflegt (Stand März 2026) und zielt auf ältere Java-Versionen; die OOP-Grundkapitel sind davon unberührt stabil. Use for: deutsche Formulierungen zum Nachlesen, nicht für Modernes.
