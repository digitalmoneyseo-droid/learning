Glossar: Klasse und Objekt

Die Begriffe aus Lektion 1, so wie dieses Workspace sie benutzt. Ein Begriff steht hier erst, wenn du ihn sicher verwenden kannst; neue kommen in jeder Lektion dazu.

Begriffe

BegriffDefinition
Klasse Der Bauplan im Programmtext. Legt Attribute und Methoden fest, die ihre Objekte haben. Sie existiert einmal pro Programm.
Englisch als Randnotiz: class
Objekt Ein konkretes Exemplar einer Klasse, erzeugt mit new. Trägt eigene Attributwerte und führt Methoden aus.
Auch: Instanz, Exemplar · engl.: object, instance
Attribut Eine Zustandsvariable, die jedes Objekt einer Klasse für sich besitzt, z. B. kontostand.
Engl.: attribute, field
Methode Eine Operation, die an einem Objekt aufgerufen wird und sein Verhalten darstellt, z. B. einzahlen(50).
Engl.: method

Klausur-Rezept: Objektzustände verfolgen

  1. Jedes new Konto(...) notieren → neues Objekt, Startwerte eintragen.ein new = ein neues Exemplar
  2. Jeden Methodenaufruf am richtigen Objekt anwenden: nur k1.einzahlen(50) ändert k1.Aufruf gilt nur fürs angesprochene Objekt
  3. Am Ende Werte je Objekt ablesen, nicht je Klasse.Werte wohnen in Objekten
